# Backpack mod
A small fabric mod for Minecraft 26.3 that adds craftable and equippable backpack.

## Features
- Craftable backpack with 36 slots
- Wear it in the chestplate slot, B opens it if you are wearing it.
- If you are holding item in hand Shift+Right click opens it and Right click equips it

## Recipe
- Leather Iron Ingot Leather
- Leather String Leather
- Leather Leather Leather

## Controls
| Action | Input |
|--------|-------|
| Wear the backpack | Right-click while holding it |
| Open worn backpack | B (rebindable in Controls) |
| Open held backpack | Shift + right-click |

## Requirements
- Minecraft 26.3
- Fabric Loader
- Fabric API
- Java 25

## Installation
1. Install Fabric Loader and Fabric API for Minecraft 26.3.
2. Download the jar from the Releases page.
3. Put it in your `.minecraft/mods` folder.

## Known issues
- A backpack can currently be moved into itself while it is open.
- The worn backpack is a flat texture; a 3D model is planned.
